# ADR 0012: Material Design 3 (MD3) 仕様に基づく UI/UX 刷新とレイアウト設計方針

## Status
Accepted

## Date
2026-05-29

## Context
プレゼンテーション層のFlet移行（[ADR 0009](file:///Users/tanakayoshitaka/Projects/password-manager/docs/adr/0009-presentation-layer-flet-integration.md)）の後、更なるユーザー体験（UX）の向上、および一貫した視覚的デザインの確保が必要となった。
また、レスポンシブな幅可変に伴うレイアウトの崩れや、エラーハンドリング表示（スナックバー）の使いにくさといった課題が存在したため、これらを解消する厳格なUI設計方針を策定した。

## Decision
**Google の Material Design 3 (MD3) 仕様に準拠した UI/UX 刷新を行い、以下の設計方針を適用する。**

1. **MD3 カラーシステムとフォントの標準化**
   - 主要なカラーパレット（Primary: `#374379`, Error: `#ba1a1a` 等）および Google Fonts の `"Inter"` フォントを各プレゼンテーションコンポーネント内で標準採用する。
2. **固定ウィンドウサイズポリシー**
   - 複数環境で一貫したデスクトップアプリケーションのレイアウトを保証するため、ウィンドウサイズを `1280x1000` で固定（`resizable = False`）とし、レスポンシブ対応による不要な幅計算処理を廃止する。
3. **マイクロインタラクションの導入**
   - ログインIDおよびパスワードのコピー時に、ボタンアイコンが一時的に緑のチェックマークに切り替わるトランジションを取り入れ、アクション成功のフィードバックを視覚的に強化する。
4. **ダイアログ表示の統一**
   - アカウントの新規登録・編集ダイアログ（`AccountDialog`）をMD3風の枠線なし入力フィールド・下線付きコンテナ形式へ刷新する。
   - 削除確認にはマテリアル警告アイコン付きのMD3風モーダルを採用する。
   - 例外発生時のエラー表示については、従来のスナックバー方式から中央配置の美しい `ErrorDialog` （MD3仕様）に統一し、操作性と視認性を高める。

## Rationale
- ✅ **一貫したUXの提供**: すべてのダイアログ、カード、アクションボタンがMD3仕様で統一されたことで、モダンで調和の取れたUIを実現。
- ✅ **保守性の向上とバグ削減**: リサイズによる複雑なコンポーネント幅再計算ロジックを廃止したことで、レイアウト崩れが発生する原因を物理的に排除し、コードの複雑性を軽減。
- ✅ **安全なエラー通知**: 画面下部で見落とされがちだったスナックバーを廃止し、モーダルなエラーダイアログを採用したことで、エラー発生の事実とメッセージが確実にユーザーに認知される。

## Consequences

### Positive
- ライトテーマを基調とした、極めてモダンで洗練されたUI/UXとなった。
- ウィンドウサイズが固定化され、余計なリサイズ連動幅計算が不要になったため、プレゼンテーション層のコードが簡素化された。

### Negative
- ウィンドウ幅を自由に変更したいユースケースには対応できなくなった。しかし、本パスワードマネージャーのコンパクトな用途においては、1280x1000固定で十分な一覧性と使い勝手が担保できると判断した。
