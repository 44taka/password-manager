# ユビキタス言語 (Ubiquitous Language)

本プロジェクト（パスワードマネージャー）における主要な用語定義です。
ドメインモデル、ソースコード、および UI において、これらの用語を一貫して使用します。

## 主要な概念

| 用語 | 英語名 | 定義 | 備考 |
| :--- | :--- | :--- | :--- |
| **アカウント** | **Account** | 特定のサービスにログインするための情報一式。 | 集約ルート（Entity） |
| **サービス名** | **service_name** | アカウントが属するサービスやサイトの名前（例: Google, GitHub）。 | |
| **ログインID** | **login_id** | サービスへのログインに使用する識別子（ユーザー名、メールアドレス等）。 | |
| **パスワード** | **password** | サービスへのログインに使用する秘密情報。 | 値オブジェクトとして定義 |
| **メモ** | **memo** | アカウントに関する補足情報や備忘録。 | |

## 技術的な識別子

| 用語 | 英語名 | 定義 |
| :--- | :--- | :--- |
| **アカウントID** | **account_id** | システム内でアカウントを一意に識別するための内部ID。UUID (v4) を使用。 |

## 更新履歴
