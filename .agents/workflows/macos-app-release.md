# 🚀 MacOSアプリリリース・ワークフロー

このファイルは、Antigravity (AIエージェント) がアプリケーションのリリースとローカルMacへのインストールを実行するための指示書です。
ユーザーから「リリースして」「ローカルにインストールして」と依頼された場合、以下の手順に沿って実行してください。

## 🎯 目的
1. `pyproject.toml` のバージョンをユーザーの指定した値に更新する。
2. 変更をGitの `main` ブランチにコミット・プッシュし、リリースタグ（`vX.Y.Z`）を打つ。
3. macOSアプリケーション（`.app`）をビルドする。
4. ビルドしたアプリを `/Applications` フォルダにインストールする。

## 📋 実行手順

### Step 1: バージョン番号の決定と更新
1. ユーザーに「次にリリースするバージョン番号（例：0.1.2）は何にしますか？」と尋ね、回答を待ちます。
2. ユーザーからバージョン番号の回答を得たら、`pyproject.toml` の `version = "..."` をその値に更新します（セマンティックバージョニング）。以降、このバージョンを `vX.Y.Z` として扱います。
3. バージョン更新を `uv.lock` に反映させます。
   - コマンド: `uv lock`

### Step 2: Git へのコミットとプッシュ
1. 変更されたファイル (`pyproject.toml`, `uv.lock`) をステージングします。
   - コマンド: `git add pyproject.toml uv.lock`
2. [.agents/rules/git-commit-style-guide.md](../rules/git-commit-style-guide.md) の規約に従い、日本語でバージョンアップのコミットを作成します（例：`chore: バージョンを vX.Y.Z に更新`）。
   - コマンド: `git commit -m "chore: バージョンを vX.Y.Z に更新"`
3. `main` ブランチの最新状態としてリモートリポジトリにプッシュします。
   - コマンド: `git push origin main`

### Step 3: Git タグの作成とプッシュ
1. 新しいバージョンの Git タグを作成します。
   - コマンド: `git tag vX.Y.Z`
2. 作成したタグをリモートにプッシュします。
   - コマンド: `git push origin vX.Y.Z`

### Step 4: アプリケーションのビルド
1. バージョン情報が正しく反映された状態でアプリをビルドします。
   - コマンド: `make build`
2. 実行の出力（標準出力）を確認し、`dist/Password Manager.app` が生成されたことを確認します。

### Step 5: アプリケーションのインストール (移動)
1. インストール時の上書きエラーを防ぐため、現在起動しているアプリを終了します。
   - コマンド: `killall "Password Manager" || true` (起動していない場合のエラーを無視するため `|| true` を付けます)
2. `/Applications` 内の既存のアプリを削除します。
   - コマンド: `rm -rf "/Applications/Password Manager.app"`
3. ビルドした新しいアプリケーションをコピーします。
   - コマンド: `cp -R "dist/Password Manager.app" "/Applications/"`
4. ユーザーにインストールが完了し、リリース作業がすべて完了したことを報告します。

## ⚠️ 注意事項
- ユーザーへのバージョン確認は必ず行い、勝手にバージョンを進めないでください。
- 万が一、いずれかのステップでエラーが発生した場合（例：Gitのコンフリクト、ビルド失敗など）、直ちに作業を中断し、ユーザーに状況を報告して指示を仰いでください。
